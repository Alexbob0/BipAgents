# Beta-Bedingungen

> Zuletzt aktualisiert: 24. Oktober 2026.

Mit der öffentlichen Beta von BipAgents kannst du die App und das Rundum-Angebot ausprobieren, bevor die Abos starten.
Sie wird von Kerfy Studio angeboten, dem Herausgeber von BipAgents.

- **Kostenlos.** Die Beta kostet nichts, und es wird kein Zahlungsmittel verlangt. Das KI-Guthaben der Beta ist
  geschenkt: Es kann weder verkauft noch erstattet werden.
- **Ohne Gewähr.** Es ist eine Testversion: Funktionen können fehlen, sich ändern, fehlerhaft sein oder ausfallen, und
  Daten können verloren gehen. Bewahre eine Kopie von dem auf, was dir wichtig ist. Die Beta wird so bereitgestellt,
  wie sie ist, ohne Gewähr, soweit das Gesetz es erlaubt.
- **Sie kann enden.** Wir können die Beta oder deine Teilnahme jederzeit beenden oder ändern, zum Beispiel wenn die
  Abos starten. Die Plätze sind begrenzt.
- **Deine Daten.** Sie werden so verarbeitet, wie es die [Datenschutzerklärung](privacy.de.md) beschreibt. Die
  [Nutzungsbedingungen](terms.de.md) und die [Richtlinie zur zulässigen Nutzung](acceptable-use.de.md) gelten ebenfalls.
- **Die Installation.** Die Beta wird über TestFlight (Apple) oder das Testprogramm von Google Play installiert: Deren
  eigene Bedingungen gelten ebenfalls.
- **Deine Rückmeldungen.** Sie sind willkommen, in der App oder an **support@bipagents.com**. Wir können sie nutzen, um
  BipAgents zu verbessern, ohne dir dafür etwas zu schulden.
